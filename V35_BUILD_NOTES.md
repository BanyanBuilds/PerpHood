# LEVERAGE X V35 — Complete Coin Trading Workspace

V35 turns the selected-token route into the primary professional trading workspace rather than a loose collection of market widgets.

## Workspace layouts

- **Trade:** market rail, chart/data workspace, order book, and unified order ticket.
- **Focus:** chart/data workspace uses the full available width.
- **Research:** market rail and expanded central data workspace without the order ticket.
- The selected layout persists locally.

## Unified execution surface

The right ticket exposes all four BattlePool actions:

- Buy
- Sell
- Long
- Short

The ticket continues to use the existing exact BattlePool quote and execution paths. Spot selling remains tied to the user's actual token inventory.

## Keyboard-first workflow

- `B` — Buy
- `Shift + S` — Spot sell
- `L` — Long
- `S` — Short
- `1–4` — 0.01 / 0.025 / 0.05 / 0.10 ETH
- `Q–R` — 2× / 5× / 10× / 20×
- `Space` — Toggle chart-focus layout

Shortcuts are ignored while typing in an input, text area, selector, or editable element.

## Live BattlePool workspace

The selected market now includes:

- Risk and solvency ribbon
- Free versus reserved WETH
- Long/short open-interest pressure
- Executable account PNL
- Nearest account liquidation distance
- One-second chart and existing risk/order overlays
- Battle map with real account liquidation markers
- Persistent position and spot manager
- Tape, orders, positions, BattlePool, traders, holders, and token information tabs

## Position controls

Leveraged positions support:

- Close 25%, 50%, 75%, or 100%
- Add collateral
- Move stop to breakeven
- Add a quick 15% take-profit target
- Executable PNL and liquidation-distance display

Spot holdings support partial or complete execution against the actual shared pool.

## Visual system

The selected-token workspace now uses the mandatory dark #333-adjacent Leverage X terminal language with readable 11–15 px working typography, sharper panels, and borders reserved for real workspace boundaries and interactive controls.
