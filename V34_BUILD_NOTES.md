# PerpHood V34 — Clean Status Hierarchy

V34 removes fake button styling from read-only terminal information.

## Changes

- The visual refresh readout now displays only the current target, such as `360 Hz`.
- Removed the FPS label, display-Hz sublabel, Auto/Manual sublabel, border, background, radius, and overdrive outline from the header readout.
- Robinhood Chain status is now plain text with its live indicator rather than a bordered control.
- Positions and portfolio readouts are plain status information.
- Bottom-bar connection and engine statuses are visually distinct from clickable tools.
- Clickable controls, inputs, menus, and buttons retain clear interactive framing.

The FPS settings remain available from the settings button, including Auto, 60, 120, 144, 240, and 360.
