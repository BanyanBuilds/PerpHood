# Leverage X V82 — Terminal Design + Broadcast Mode

V82 brings the terminal back to one unified visual language inspired by the cleanliness and spacing discipline of modern professional terminals.

## Included

- Replaced visible P1/P2/P3 preset cards with compact named Standard, Fast, and Assault controls while preserving existing stored preset keys.
- Reduced preset visual weight and clarified the difference between trading presets and execution routing.
- Refined the connected-wallet profile drawer so identity, metrics, PNL, navigation, access, and actions share the same surfaces, spacing, radii, and typography.
- Added a first-class Broadcast button in the terminal top navigation.
- Added viewer-first live PNL and active-position graphics with high legibility at streaming resolutions.
- Added Broadcast privacy masking for wallet-sensitive position values.
- Added responsive behavior that keeps one primary position visible on smaller screens.

## Security

No secrets were added. Private keys, admin credentials, RPC secrets, and deployment credentials remain server-only Vercel environment variables and are excluded by `.gitignore`.
